# Ясно: приложение для родителей школьного класса

Устанавливается на Android из браузера Chrome как обычное приложение (при желании упаковывается в APK для Google Play).
Работает без интернета, при появлении сети данные сами синхронизируются между телефонами.

## Что нужно для синхронизации и уведомлений
Один проект **Firebase** от Google. Для приложения и базы тариф Spark бесплатный.
Для напоминаний нужны облачные функции, а они требуют тариф **Blaze** (привязать карту; при небольшом классе расходы обычно около нуля, так как есть бесплатный лимит). Поставьте в Google Cloud бюджетное оповещение на 1-5 долларов.

### Шаг 1. Проект
console.firebase.google.com → «Добавить проект». Затем:
- Build → Authentication → Sign-in method → включить **Anonymous**.
- Build → Firestore Database → Create database (запомните регион) → Production.

### Шаг 2. Правила доступа
Firestore → Rules → вставить содержимое `firestore.rules` → Publish. Именно они делают «коалицию»: данные класса видят только те, кто вошёл по коду.

### Шаг 3. Ключи приложения
Project settings (шестерёнка) → Your apps → значок `</>` → зарегистрировать приложение → скопировать значения в `firebase-config.js`.

### Шаг 4. Ключ уведомлений
Project settings → Cloud Messaging → Web Push certificates → Generate key pair → скопировать ключ в поле `vapidKey` файла `firebase-config.js`.

### Шаг 5. Настройки функций
В `functions/index.js` вверху укажите свой часовой пояс (`TZ`), регион базы (`REGION`) и адрес приложения (`APP_URL`, он будет известен после первого деплоя; можно задеплоить дважды).

### Шаг 6. Выложить
```
npm install -g firebase-tools
firebase login
firebase init        # выберите свой проект; Hosting (public: .), Firestore, Functions (JavaScript, не перезаписывая файлы)
cd functions && npm install && cd ..
firebase deploy
```
Появится адрес вида `https://yasno-xxxx.web.app`.

### Шаг 7. Установка на Android
Открыть адрес в Chrome → меню ⋮ → «Установить приложение» → в приложении раздел «Ещё» → «Включить напоминания».

## Как это работает
- Первый родитель регистрируется, создаёт класс и становится старостой. Он получает **код из 6 символов**.
- Остальные входят по коду или по ссылке `...?code=ABC123`. Без кода в класс попасть нельзя.
- Семья (мама, папа, ребёнок) соединяется по своему коду. В бесплатной версии максимум 3 человека, это проверяет и база.
- Староста может передать свою роль другому родителю (раздел «Класс»).
- При первом запуске показываются подсказки.

## Напоминания
- Утром (7:30) приходит список на сегодня: дела, домашка и сборы со сроком в ближайшие 3 дня.
- Вечером (18:00) приходит список на завтра.
- Сразу после появления нового дела, домашки или сбора уведомление получает весь класс, кроме автора.
- Напоминания строятся по **дате**, поэтому в формах есть поле даты. Из чата даты подставляются по словам «завтра», «в пятницу» и т. п.
- Время отправки меняется в `functions/index.js` (строки с `schedule`). Поддерживаются только устройства с Chrome на Android. На iPhone уведомления работают с iOS 16.4 и только если приложение добавлено на главный экран.

## Политика конфиденциальности
Файл `privacy.html` лежит рядом с приложением и открывается по адресу `https://ваш-адрес/privacy.html`.
**Перед публикацией** найдите в нём розовые пометки `[ЗАПОЛНИТЬ ...]` и вставьте своё имя или название, e-mail, регион базы и дату.
Этот адрес нужно указать в Google Play. Текст составлен по тому, как приложение реально работает, но это не юридическая консультация: покажите его юристу, особенно если вы работаете с данными детей и людей из другой страны.

В приложении уже есть: согласие с политикой при регистрации, ссылка в разделе «Ещё» и кнопка «Удалить мой аккаунт» (Google Play требует возможность удаления в самом приложении).

## APK и Google Play
pwabuilder.com → вставить адрес приложения → Android → скачать пакет. Нужен аккаунт разработчика Google Play (разовый платёж 25 долларов) и ссылка на политику конфиденциальности.

## Что пока упрощено
1. **Вход** анонимный: аккаунт привязан к телефону. Если очистить данные приложения, нужно войти заново по кодам класса и семьи. Надёжнее вход по SMS (Authentication → Phone, платный).
2. **Подписка Pro** (до 5 человек в семье) не подключена: нужен Google Play Billing или RevenueCat. Лимит семьи хранится в `families.limit`.
3. **Защита базы.** Подключите Firebase App Check, чтобы базой пользовалось только ваше приложение.
4. Шрифты грузятся с серверов Google (это указано в политике). Для полной приватности скачайте их и положите рядом с приложением.
5. Ежедневные списки читают все классы подряд. Для сотен классов функции придётся оптимизировать.
