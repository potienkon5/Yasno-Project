Установка

«Ясно» всегда под рукой

Для Android — готовый APK. Для iPhone — веб-приложение, которое добавляется на экран «Домой» через Safari.

A Android

Скачать и установить

Откройте ссылку с телефона, скачайте APK и установите приложение. Если Android запросит разрешение на установку из браузера, подтвердите его в настройках устройства.

Скачать APK для Android ↓

Файл загружается из публичного GitHub Releases. Аккаунт GitHub не требуется. Если открылось приложение GitHub — выберите открытие ссылки в браузере.

i iPhone / iPad

Добавить на экран «Домой»

Версия для iPhone работает как веб-приложение (PWA) — без App Store и установки APK.

  1. Откройте кнопку ниже в Safari на iPhone.
  2. Нажмите «Поделиться» (значок квадрата со стрелкой).
  3. Выберите «На экран „Домой“» / «Add to Home Screen».
  4. Нажмите «Добавить» и запускайте «Ясно» с домашнего экрана.
Открыть «Ясно» для iPhone ↗

Уведомления и работа в фоне на iOS зависят от версии системы, разрешений и настроек веб-приложения. Некоторые нативные Android-функции недоступны.

Частые вопросы

Отвечаем на важное

Нужно ли всем родителям скачивать приложение?

Для совместной работы участникам нужен доступ к «Ясно». На Android можно установить APK, на iPhone — добавить веб-версию на главный экран. Каждый взрослый входит под своей учётной записью.

Как присоединиться к существующему классу?

Попросите у старосты шестизначный код класса. После регистрации выберите присоединение к классу и введите этот код.

Видят ли родители мои отметки о сборах?

Участники класса могут видеть сведения о сборах и статусах оплаты в интерфейсе. Не используйте приложение для хранения банковских карт или платёжных реквизитов.

Можно ли подключить маму и папу к одной семье?

Да. В одной семье поддерживается до трёх учётных записей. Приглашение происходит по отдельному коду семьи.

Приходят ли уведомления на iPhone?

На iPhone веб-версия работает иначе, чем Android APK. Фоновые уведомления требуют отдельной серверной настройки Web Push и не гарантируются текущей версией. Основные дела и задания доступны при открытии приложения.

Это интернет-магазин или сервис оплаты сборов?

Нет. «Ясно» помогает вести учёт денежных сборов и отмечать оплату. Само приложение не принимает банковские платежи на этой странице.
