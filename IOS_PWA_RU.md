# Ясно на iPhone — бесплатная PWA через GitHub Pages

## Как это работает
Публикуем `capacitor/www` (актуальную веб-версию приложения) на HTTPS через GitHub Actions. **Это не сборка IPA**: Apple Developer, Xcode и Mac не требуются. Android APK и workflow `build-android.yml` остаются отдельно.

## Настройка владельцем репозитория
1. Влить PR с workflow `.github/workflows/deploy-pwa.yml` в `main`.
2. GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. GitHub: **Actions → 3 - Publish iPhone PWA (GitHub Pages) → Run workflow → Run workflow**. При изменениях в `capacitor/www` workflow сработает автоматически.
4. Дождаться успешного deployment. Сайт: **https://potienkon5.github.io/Yasno-Project/**.
5. Supabase: Authentication → URL Configuration: добавить `https://potienkon5.github.io/Yasno-Project/**` в Redirect URLs. Настроить Site URL на реальный стабильный адрес, если это основной веб-сайт. Существующие адреса других платформ не удалять.
6. Проверить `capacitor/www/supabase-config.js`: URL и publishable/anon key должны относиться к рабочему проекту. **Никогда не помещать service_role, VAPID private key или секрет вебхука в публичный репозиторий.**
7. **До приглашения реальных семей** заполнить `capacitor/www/privacy.html` (владелец/почта/регион/дата) и проверить настройки RLS.

## Установка на iPhone
iOS 16.4+ (для Web Push). Открыть HTTPS-сайт **в Safari**, нажать **Поделиться → На экран «Домой» → Добавить**. Запустить «Ясно» с нового значка на домашнем экране, а не в обычной вкладке Safari. Вкладка браузера не имеет того же разрешения на Web Push.

## Уведомления и точные сроки
- PWA Web Push работает на поддерживаемых iOS для установленных на экран «Домой» веб-приложений, при явном разрешении пользователя.
- `capacitor/www/supabase-config.js`: `vapidPublicKey` сейчас пуст. Без публичного VAPID-ключа подписка Web Push **не создаётся**. Простое нажатие «Включить» не гарантирует фоновых уведомлений.
- Нужны реальная пара VAPID ключей (публичный ключ в клиенте, приватный — только Supabase Edge Function secrets), таблица `push_subscriptions` и запущенный механизм отправки через `supabase/functions/notify`.
- Для **уведомления ровно в срок отдельной задачи или сбора** требуется серверный планировщик/очередь, который учитывает время и часовой пояс задачи. Существующая функция `notify` обрабатывает новые записи и общие дневные напоминания; отдельную отправку в индивидуальный час срока пока не реализует.
- Для диагностики после настройки: с домашнего экрана «Ясно» → «Ещё» → «Включить напоминания», проверить системные разрешения и реальную доставку закрытому приложению.
- На iOS нет Android Capacitor LocalNotifications и нет установки APK. Обновления PWA доставляются при следующем открытии сайта (зависит от кеширования).

## Ссылки-приглашения
Поскольку хостинг расположен в подпапке, правильная форма ссылки:
`https://potienkon5.github.io/Yasno-Project/?code=ABC123`.
Текущая функция `inviteUrl()` в `capacitor/www/index.html` использует `location.pathname`, поэтому сохраняет путь `/Yasno-Project/` и код приглашения. Старые ссылки `localhost` на других устройствах не работают.

## Тесты
1. Открыть URL на iPhone Safari и добавить на домашний экран.
2. Зарегистрировать тестового пользователя, подтвердить email, зайти в аккаунт.
3. Создать тестовый класс; отправить ссылку другому устройству; проверить, что путь начинается с `/Yasno-Project/?code=` и вступление работает.
4. Изменить задачу на Android и проверить синхронизацию в PWA iPhone.
5. Проверить офлайн-открытие и обновление после нового деплоя.
6. Отдельно проверить пуш после реальной настройки VAPID/серверного расписания.

## Примечание о безопасности
Репозиторий и сайт публичны. Публичный anon key допустим **только с корректными Supabase RLS**. Детские персональные данные требуют особого внимания к конфиденциальности. GitHub Pages подходит для статического фронтенда, но не заменяет сервер планировщика уведомлений.
