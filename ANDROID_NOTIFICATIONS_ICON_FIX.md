# Ясно — исправление уведомлений и чёрной рамки иконки

## Почему напоминание могло не появиться
В Android 12–14 есть **два отдельных разрешения**: обычные уведомления и **«Будильники и напоминания»** для точного расписания. Без второго точное срабатывание может быть недоступно. Также прежняя версия запоминала, что событие запланировано, и не сверяла это с фактической очередью Android после обновления или изменения разрешений.

## Как проверить после установки нового APK
1. Откройте **Настройки Android → Приложения → Ясно → Уведомления**: разрешите уведомления.
2. В разделе специальных разрешений Android откройте **«Будильники и напоминания»** для Ясно и включите доступ, если настройка есть. Путь зависит от модели телефона. В Ясно доступна кнопка **«Разрешить точное время»**.
3. Откройте **Ясно → Ещё → Напоминания → Проверить состояние**. В приложении появятся разрешение уведомлений, количество событий в очереди Android и состояние точных будильников.
4. Нажмите **«Тест через 10 секунд»**. Оставьте уведомления включёнными; при недоступных точных будильниках Android может доставить сообщение позже. Повторите после разрешения точного времени.
5. Создайте дело **с датой сегодня и временем через 3–5 минут**, затем снова нажмите «Проверить состояние». Значение «в очереди Android» должно возрасти.
6. Если событие уже в прошлом (выбранная дата/время наступила до записи), оно не планируется.
7. Если тест запланирован, но не приходит, проверьте режим энергосбережения и ограничения фоновой активности для «Ясно».

## Иконка
Раньше PNG содержал непрозрачные чёрные пиксели по краям. В GitHub Actions перед созданием Android-иконок выполняется `capacitor/fix-icon-background.py`: он заменяет связанный с внешней кромкой чёрный фон на тёмно-синий #283771. Никаких изменений Supabase для этого не требуется.

Изменения действуют только в APK после новой сборки. Подписывайте тем же ключом и устанавливайте поверх старого приложения, не удаляя данные.
